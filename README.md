
# Number Base Conversion — Java

A Java-based number system conversion program developed as part of a university Computer Architecture course.

## Overview

This project explores the representation and conversion of numbers between different numeral systems, including binary, octal, decimal, and hexadecimal.

The project demonstrates fundamental computer architecture concepts relating to numerical representation and arithmetic operations.

## Technologies

- Java
- Object-Oriented Programming (OOP)
- Number System Conversion Algorithms

## Features

The project focuses on conversions between common number systems:

- **Binary (Base 2)** — Uses digits 0 and 1.
- **Octal (Base 8)** — Uses digits 0–7.
- **Decimal (Base 10)** — Uses digits 0–9.
- **Hexadecimal (Base 16)** — Uses digits 0–9 and A–F.

## Concepts Covered

- Positional number systems
- Binary, octal, decimal, and hexadecimal representations
- Mathematical operations for base conversion
- Algorithm implementation in Java

## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- A Java IDE or text editor

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/notmej/baseConv.git
   ```

2. Navigate to the project directory:

   ```bash
   cd baseConv
   ```

3. Open the project in your preferred Java IDE.
4. Locate and run the main application class.

## Project Context

Developed as an academic Computer Architecture project to explore how computers represent and process numerical information using different number systems.
